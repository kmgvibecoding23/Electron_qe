# Электронная очередь на налив нефтепродуктов — демо-прототип

Реализация по [PRD_1.md](PRD_1.md) на чистых HTML + CSS + JavaScript, без фреймворков и сборщиков.

## Запуск

Откройте `index.html` в браузере (Chrome / Edge / Firefox). Сервер не нужен.
При первом запуске система сама заполняется демо-данными.

## Демо-пользователи

| Роль | Логин | Пароль | Описание |
|---|---|---|---|
| Администратор | `admin` | `admin123` | Полный доступ: аналитика, брони, пользователи, справочник, настройки |
| Охранник | `guard` | `guard123` | Контроль въезда и выезда |
| Товарная лаборатория | `lab` | `lab123` | Партии готового продукта |
| Доверенное лицо | `trustee1` | `trust123` | ТОО «Транзит Ойл», 3 машины |
| Доверенное лицо | `trustee2` | `trust123` | ТОО «КазТрансАвто», 3 машины |
| Доверенное лицо | `trustee3` | `trust123` | ТОО «Степной перевозчик»: 3 неявки, бронирование заблокировано санкцией |
| Охранник | `guard2` | `guard123` | Заблокирован: показывает отказ во входе |

Таблица также есть на странице входа: клик по строке подставляет логин и пароль.

## Демо-данные

- **Продукты:** АИ-92, АИ-95, ДТ летнее, ДТ зимнее, Топливо ТС-1, Мазут М-100 (неактивен).
- **Партии:** 3 закрытые исторические и 5 открытых. ДТ зимнее начинает выдаваться через 2 дня.
- **Машины:** 8 автоцистерн у трёх организаций. Есть `А123ВС 77` для проверки поиска (`а123вс 77`, `A123BC77`).
- **Движение:**
  - история за 20 дней: отгрузки, неявки, отмены;
  - сегодня: одна машина уже выехала, две на территории, три ожидаются;
  - брони на ближайшие дни.
- Сбросить данные к исходным: **Администратор → Настройки → «Сбросить демо-данные»**.

## Решения по открытым вопросам PRD

| # | Вопрос | Решение |
|---|---|---|
| 1 | Хранение | `localStorage` (прототип) |
| 2 | Единица учёта | Только тонны |
| 3 | Слоты | Бронь на день, внутри дня живая очередь по факту въезда. Каждому посту назначена вместимость в машинах в день (по умолчанию 15) |
| 4 | Посты | Оба поста наливают любой продукт. Пост назначается автоматически, туда, где меньше броней на этот день. Администратор может переназначить |
| 5 | «Выехала» | Отмечает охранник |
| 6 | Санкции | 3 неявки за 30 дней → запрет бронирования на 7 дней от последней неявки. Параметры меняются в настройках. Администратор может снять санкции досрочно |
| 7 | Организация | Одна организация — одно доверенное лицо (проверяется при создании пользователя) |
| 8 | Лимит | 100 т в сутки на доверенное лицо (настраивается) |

## Структура

```

admin-*.html               страницы администратора
guard.html                 контроль въезда

css/style.css

js/pages/*.js              логика страниц
```

## Ограничения прототипа

Данные хранятся только в этом браузере. Бронь, сделанную на одном компьютере, охранник на другом не увидит.
Пароли защищены лишь демо-хэшем. Для промышленной эксплуатации нужен серверный слой.
Он заменяет только `js/storage.js`, а проверки оттуда переносятся на сервер.
